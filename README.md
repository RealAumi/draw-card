# draw-card

一个用于优化现场抽奖体验的网页应用

## 技术栈

- **Bun** - JavaScript 运行时和包管理器
- **React 19** - 用户界面库
- **TypeScript** - 类型安全的 JavaScript
- **Tailwind CSS v4** - 实用优先的 CSS 框架
- **React Router** - 客户端路由
- **Vite** - 前端构建工具

## 功能特性

### 配置页面 (`/`)

- 📊 统计信息：奖项总数、概率总和验证（必须等于 100%）、总库存
- 📝 奖项列表：显示颜色、名称、比例和库存
- ➕ 添加奖项：自定义奖项名称、中奖比例、库存数量和颜色
- ✏️ 编辑奖项：修改现有奖项的属性
- 🗑️ 删除奖项：移除不需要的奖项
- 🎨 颜色选择器：8 种预设颜色可选
- ✅ 实时验证：概率总和必须等于 100%

### 抽奖页面 (`/lottery`)

- 🎡 全屏大转盘：基于奖项比例动态生成扇形区域
- 🎯 红色指针：固定在顶部，指示中奖位置
- ⚡ 流畅动画：5 秒旋转动画，带缓动效果
- 🎉 中奖提示：弹窗显示中奖奖项和剩余库存
- 📦 库存管理：每次抽奖后自动减少库存
- 🛡️ 防护机制：库存为 0 时自动从抽奖池中移除

## 快速开始

### 安装依赖

```bash
bun install
```

### 开发模式

```bash
bun run dev
```

访问 http://localhost:5173 查看应用

### 生产构建

```bash
bun run build
```

### 预览生产版本

```bash
bun run preview
```

## 使用说明

1. **配置奖项**
   - 在首页配置奖项，设置名称、比例和库存
   - 确保所有奖项的比例总和等于 100%
   - 可以添加、编辑或删除奖项

2. **开始抽奖**
   - 点击"开始抽奖"按钮进入抽奖页面
   - 点击"开始抽奖"按钮，转盘开始旋转
   - 等待转盘停止，查看中奖结果
   - 点击"继续抽奖"进行下一轮

3. **返回配置**
   - 在抽奖页面点击"返回配置"按钮返回配置页面
   - 可以随时调整奖项配置

## 默认奖项

应用预配置了 4 个默认奖项：

- 🥇 一等奖：5% 概率，1 个库存
- 🥈 二等奖：10% 概率，3 个库存
- 🥉 三等奖：20% 概率，5 个库存
- 🎁 参与奖：65% 概率，100 个库存

您可以在配置页面自由修改这些奖项。
